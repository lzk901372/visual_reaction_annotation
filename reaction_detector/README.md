# Reaction Detector

This folder contains frame-level reaction intensity detectors for RealTalkListening and Seamless clips. Each detector reads a usable-list text file (generated by `generate_usable.py`), loads the corresponding FER emotion CSV and face-analysis PKL files, and writes one CSV per video with a reaction intensity score for every frame.

## Supported Reactions

The current detectors cover six reaction types:

- `smiling`
- `laughing`
- `frowning`
- `surprised`
- `nodding`
- `head_shaking`

Each reaction has its own subfolder with a Python detector and, in most cases, a shell launcher. Outputs are usually written under each reaction folder, for example:

```text
reaction_detector/smiling/output/
reaction_detector/smiling/output_seamless/
```

## Input Format

Most detector scripts read a usable-list file such as:

```text
usable_realtalk.txt
usable_seamless_2.txt
```

Each line should contain three comma-separated paths:

```text
<video_path>,<fer_csv_path>,<face_analysis_pkl_path>
```

The scripts use:

- `video_path` for optional overlay rendering and output path structure.
- `fer_csv_path` for emotion probabilities such as `happy`, `sad`, `angry`, and `surprise`.
- `face_analysis_pkl_path` for frame-level face detection, blendshapes, and head-pose signals.

## Per-Reaction Detectors

The expression-based detectors combine FER scores with face blendshape signals:

- `smiling/run_smiling_intensity_mt.py`: uses FER `happy` and smile blendshapes.
- `laughing/run_laughing_intensity_mt.py`: uses FER `happy`, smile blendshapes, and jaw opening.
- `frowning/run_frowning_intensity_mt.py`: uses FER `sad`/`angry`, frown-related blendshapes, brow movement, and AU04-like proxies.
- `surprised/run_surprised_intensity_mt.py`: uses FER `surprise`, jaw opening, eye widening, and brow movement.

The motion-based detectors use head-pose dynamics from the PKL files:

- `nodding/run_nodding_intensity_mt_v2.py`: detects pitch oscillation and suppresses yaw-dominant motion.
- `head_shaking/run_head_shaking_intensity_mt.py`: detects yaw oscillation and suppresses pitch-dominant motion.

Each detector applies smoothing, event gating, and minimum event-length constraints. Nodding and head-shaking also include hard motion constraints such as minimum peak-to-valley angle, peak velocity, and oscillation cycles.

## Output Format

Each individual detector writes a CSV with:

```text
frame_index,<reaction>_intensity
```

For example:

```text
frame_index,smiling_intensity
0,0.000000
1,0.235421
```

Scores are frame-level intensities, normally clipped to the range `[0, 1]`.

## Running Detectors

Use the shell launchers inside each reaction folder for common configurations:

```bash
bash smiling/run_smiling_intensity_mt.sh
bash laughing/run_laughing_intensity_mt.sh
bash frowning/run_frowning_intensity_mt.sh
bash surprised/run_surprised_intensity_mt.sh
bash nodding/run_nodding_intensity_mt_v2.sh
bash head_shaking/run_head_shaking_intensity_mt.sh
```

You can also call the Python scripts directly:

```bash
python smiling/run_smiling_intensity_mt.py \
  --usable_txt /data/zikai/Data/RealTalkListening/reaction_detect/usable_realtalk.txt \
  --output_dir /data/zikai/Data/RealTalkListening/reaction_detect/reaction_detector/smiling/output \
  --original_root /data/zikai/Data/RealTalkListening/Original \
  --num_workers 8
```

Useful common options include:

- `--validate`: process a random subset instead of the full usable list.
- `--validate_n`: number of validation samples.
- `--validate_seed`: random seed for validation sampling.
- `--render_overlay_video`: render videos with frame-level intensity text overlaid.
- `--render_overlay_video_output_dir`: output folder for overlay videos.
- `--num_workers`: number of parallel worker threads.

## Combining Reactions

After the six reaction folders have produced their per-reaction CSVs, run:

```bash
python combine_reactions.py
```

`combine_reactions.py` reads the six reaction outputs:

- `smiling_intensity`
- `laughing_intensity`
- `frowning_intensity`
- `surprised_intensity`
- `nodding_intensity`
- `head_shaking_intensity`

For each frame, it keeps only the reaction with the highest positive intensity and sets all other reactions to `0.0`. The combined output has this format:

```text
frame_index,smiling,laughing,frowning,surprised,nodding,head_shaking
```

This creates a mutually exclusive frame-level reaction label representation.

## Sampling Reaction Videos

`sample_reaction_videos.py` can sample clips with clear reaction evidence and render overlay videos for inspection. Notice that this script is only built for single-class reaction score overlay, not 6-class.

Example:

```bash
python sample_reaction_videos.py \
  --reaction frowning \
  --number 20
```

The script searches the selected reaction folder for existing intensity CSVs, filters candidates by peak score, consecutive active frames, and active-frame ratio, then writes sampled overlay videos under that reaction folder.

## Maintenance Utility

`fix_truncated_seamless_filenames.py` fixes truncated CSV filenames in Seamless reaction output folders by matching them against expected video stems from `usable_seamless_2.txt`. This is because weirdly some names are fruncated, so we need to go back to `usable_seamless_2.txt` to rename them.

Preview changes without renaming files:

```bash
python fix_truncated_seamless_filenames.py --dry_run
```

Apply the fixes:

```bash
python fix_truncated_seamless_filenames.py
```

## Notes

- The scripts are designed for batch processing and preserve the relative folder structure under `--original_root`.
- The output folders may contain many generated CSVs and optional overlay videos.
- For nodding-specific tuning guidance, see `nodding/README_nodding_params.md`.
- For most reaction detectors, one can go to the function `compute_(reaction name)_intensity` function to finetune some parameters for better reaction detection.
