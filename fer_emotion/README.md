# FER Emotion Detection

This directory contains scripts for facial emotion recognition (FER) on videos. The pipeline analyzes videos frame by frame and saves emotion scores to CSV files. It is used for the `RealTalkListening` data processing workflow as a template, but the multi-GPU script can also process other video directories through command-line arguments.

The resulting outputs, containing frame-wise seven-class emotion confidences, can be used for reaction-score analysis.

## Files

- `detect_multi_gpu.py`: Recommended batch inference entry point. It supports multi-GPU processing, multiple worker processes, skipping existing CSV files, and limiting the number of videos for debugging.
- `run_detect_multi_gpu.sh`: Example multi-GPU launch script. It currently processes `/data/zikai/Data/Seamless` and writes results to `output_seamless`.
- `detect.py`: Single-GPU/debug script. It currently contains a hard-coded sample video path and is better suited for quick verification.
- `run_detect.sh`: Simple wrapper for running `detect.py`.
- `examine_output.py`: Checks whether each output CSV has the same number of data rows as the corresponding video frame count, and writes incomplete results to a text file. This check ensures consistency because for some videos, data rows are less than actual video frame count.

## Environment

Running inside a Conda environment is recommended, especially when using GPU acceleration with TensorFlow/CUDA. The shell scripts prepend the current Conda environment library path to `LD_LIBRARY_PATH`.

Main Python dependencies:

```bash
pip install fer pandas tqdm opencv-python
```

For GPU acceleration, install a TensorFlow version compatible with the CUDA/cuDNN versions on the machine.

## Quick Start

Use the multi-GPU launch script:

```bash
bash run_detect_multi_gpu.sh
```

The default command is equivalent to:

```bash
python detect_multi_gpu.py \
  --input-root "/data/zikai/Data/Seamless" \
  --output-root "./output_seamless" \
  --gpus "0,1" \
  --workers-per-gpu 1 \
  --batch-size 512 \
  --size-multiplier 1 \
  --mtcnn
```

To process videos under `RealTalkListening/Original`, pass the paths explicitly:

```bash
python detect_multi_gpu.py \
  --input-root "/data/zikai/Data/RealTalkListening/Original" \
  --output-root "./output" \
  --gpus "0,1" \
  --workers-per-gpu 1 \
  --batch-size 64 \
  --size-multiplier 1 \
  --mtcnn
```

A consecutive workflow will be: run `run_detect_multi_gpu.sh`, and then run `examine_output.py` to check if any mismatch exists.

## Common Arguments

- `--input-root`: Root directory containing input videos. The script recursively finds `.mp4` files.
- `--output-root`: Output directory. Defaults to `output`. This newly created folder will contain csv files for each video in their original relative directory structure compared to `--input-root`.
- `--gpus`: GPU IDs to use, for example `0` or `0,1,2,3`.
- `--workers-per-gpu`: Number of worker processes per GPU. Defaults to `1`.
- `--batch-size`: Batch size passed to `video.analyze()`.
- `--size-multiplier`: Size multiplier passed to `video.analyze()`.
- `--save-video`: Save annotated output videos.
- `--save-frames`: Save per-frame images.
- `--force`: Re-process videos even if the output CSV already exists.
- `--max-videos`: Maximum number of videos to process. Useful for debugging.

## Output Structure

CSV files are organized by the parent directory of each input video:

```text
output_root/
  video_parent_dir/
    emo_scores/
      video_name.csv
```

For example, this input video:

```text
/data/zikai/Data/RealTalkListening/Original/-1wCGAxqT_4/0001.mp4
```

produces this output CSV:

```text
output/-1wCGAxqT_4/emo_scores/0001.csv
```

Each CSV is generated by `fer.Video.to_pandas()` and usually contains per-frame face detection results and emotion scores.

## Check Output Completeness

After inference, run:

```bash
python examine_output.py
```

The script will:

1. Scan the original video directory.
2. Scan the output CSV directory.
3. Match videos with CSV files.
4. Compare each video frame count with the number of CSV data rows.
5. Write mismatched results to `incomplete_csv_seamless.txt`.

Note that the input, output, and result paths in `examine_output.py` are currently hard-coded:

```python
ORIGINAL_DIR = Path("/data/zikai/Data/Seamless")
OUTPUT_DIR = PROJECT_ROOT / "reaction_detect" / "fer_emotion" / "output_seamless"
RESULT_FILE = PROJECT_ROOT / "reaction_detect" / "fer_emotion" / "incomplete_csv_seamless.txt"
```

Update these constants before checking another dataset.

## Debugging Tips

Start with a small number of videos to verify the environment and output format:

```bash
python detect_multi_gpu.py \
  --input-root "/path/to/videos" \
  --output-root "./output_debug" \
  --gpus "0" \
  --workers-per-gpu 1 \
  --batch-size 64 \
  --max-videos 2 \
  --mtcnn
```

If CUDA, TensorFlow, or shared library errors occur, check:

- The Conda environment is activated.
- `CONDA_PREFIX` is set.
- `LD_LIBRARY_PATH` includes `${CONDA_PREFIX}/lib`.
- TensorFlow, CUDA, and cuDNN versions are compatible.
